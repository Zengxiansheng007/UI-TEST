- **A · TODO-P0-001** 核对初始列表为空，输入并新增 `Buy groceries`，列表恰好出现一行，行标签匹配，输入框清空，页面显示 `1 item left`。每次有 3 个通过的步骤和对应截图，消耗 1 次获准提交。
- **B · TODO-P0-002** 核对相同的新增结果，再核对复选框从未勾选变为勾选，页面显示 `0 items left`，并出现 `Clear completed`。每次有 5 个通过的步骤和对应截图，消耗 2 次获准提交。
- 十例分别核对 ExecutionContextV5 身份、单例批准、SessionResultV2 的预期和实际节点、RunResultV5 的步骤和最终业务状态、EvidenceIndex、finalization commit、receipt、terminal、逐步 PNG 及 trace。每个进程的实际退出均为 0。双 worker 模式的两个节点共用一次 controller 退出。
