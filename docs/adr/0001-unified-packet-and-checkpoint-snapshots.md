# 交接信息归统一主 Packet，运行身份归 checkpoint 执行快照

本次契约对齐选择升级主 Packet 统一承载交接信息，并让每次 checkpoint 执行快照包含完整任务身份，再由快照生成 Packet；不采用独立交接上下文或生成时另传当前身份作为最终接口方向。这样接手方和快照消费者能够从约定产物获得完整任务信息，代价是同步主契约、checkpoint 生产者和相关消费者；可复用定义与历史执行快照必须区分，不能把历史运行成功当作当前运行成功。

这项选择来自用户 Q002/Q003 的明确答复及 2026-11-18 对 S1 的确认。新执行只使用新契约，旧产物保留查看，不增加自动迁移续跑能力，以控制 POC 的兼容维护范围。具体版本编号与字段布局由后续规格固定；本记录随[需求 1.0](../requirements/ui-test-contract-alignment.md)一同审阅，不代表实现完成。
